# 坦克大战 Tank Battle

一个纯 HTML + Canvas + JavaScript 实现的网页坦克大战小游戏，零依赖，用浏览器打开即可游玩。

## 玩法

- **移动**：方向键 `↑ ↓ ← →` 或 `WASD`
- **开火**：`空格` 或 `J`
- **暂停 / 继续**：`P`
- 保卫画面底部的基地，消灭本关所有敌方坦克即可过关
- 砖墙可被击碎；钢墙、水面无法通行；草丛会遮挡坦克
- 击毁**闪烁的装甲坦克**会随机掉落道具：
  - 🛡 盾 —— 短暂无敌
  - ❤ 命 —— 生命 +1
  - 💥 雷 —— 全屏消灭场上所有敌人
  - ⚡ 力 —— 炮弹可击穿钢墙

## 敌人类型

| 类型 | 生命 | 速度 | 特点 |
| --- | --- | --- | --- |
| 步兵 | 1 | 普通 | 基础敌人 |
| 快速 | 1 | 快 | 移动快 |
| 重装 | 3 | 慢 | 需命中 3 次 |
| 火力 | 1 | 中 | 射速快 |
| 装甲 | 4 | 慢 | 闪烁，击毁后掉落道具 |

## 如何运行

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

也可以部署到任意静态托管平台（GitHub Pages、Vercel、Netlify 等）。

### GitHub Pages 部署

1. 仓库 **Settings → Pages**
2. Source 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`
3. 保存后，即可通过 `https://<用户名>.github.io/<仓库名>/` 访问

## 技术实现

- 原生 Canvas 2D 渲染，`image-rendering: pixelated` 复古像素风
- `requestAnimationFrame` 游戏主循环，基于 `dt` 的帧率无关移动
- Web Audio API 合成音效（射击、爆炸、道具等）
- 支持键盘与触屏（移动端屏幕按键）操作
